# Bannerlord Compatibility Intelligence (BCI)

**Локальный инструмент для анализа совместимости модов Mount & Blade II: Bannerlord.**

[English version](README.md) · [Русская версия](README_RU.md)

[Development roadmap](ROADMAP.md) · [Дорожная карта](ROADMAP_RU.md)

BCI разрабатывается, чтобы помогать игрокам понимать, как моды Bannerlord могут взаимодействовать друг с другом, находить потенциальные риски несовместимости и разбираться в проблемах на основе технических свидетельств и контролируемых игровых тестов.

Долгосрочная цель проекта — перейти от простых предупреждений о совпадении файлов к доказательной диагностике: объяснять, что именно может быть затронуто, почему сочетание модов вызывает подозрение и какие варианты решения можно проверить.

## Статус проекта

**Текущий этап: 0.3.0-alpha — проверка и валидация анализатора.**

Текущий прототип для Windows x64 запускается локально и проходит функциональное тестирование. В существующий объём альфа-версии входят начальные проверки модулей и порядка загрузки, анализ XML, локальные HTML/JSON-отчёты, локальная база SQLite, а также компоненты для записи результатов тестирования и экспериментов с обучением модели.

Это ранняя разработка, а не стабильный релиз. Точность и полнота анализатора ещё проверяются на реальных сборках модов Bannerlord. Сборка установщика Windows пока не выдала подтверждённый релизный пакет; стабильных загрузок на GitHub сейчас нет.

См. [ветку разработки 0.3.0-alpha](https://github.com/VoodyWoodman/BCI/tree/release/0.3.0-alpha) и [историю сборок GitHub Actions](https://github.com/VoodyWoodman/BCI/actions).

## Принципы проекта

- **Доказательства вместо догадок.** Выводы должны опираться на конкретные файлы, данные, правила, логи или воспроизводимые тесты.
- **Совпадение — ещё не конфликт.** Если два мода затрагивают один файл, XML-узел или метод, это не означает, что они обязательно мешают друг другу.
- **Честное обозначение неопределённости.** Подтверждённые ошибки, потенциальные риски, безопасные переопределения и неизвестные случаи должны различаться.
- **Локальная работа в первую очередь.** Базовый принцип — анализ и хранение данных на компьютере пользователя без обязательных облачных сервисов.
- **Решение остаётся за пользователем.** Программа должна объяснять компромиссы, а не незаметно менять сборку модов.
- **Никаких невыполнимых обещаний.** BCI стремится уменьшать проблемы совместимости, но не может гарантировать игру без вылетов.

## Планируемые возможности

По мере развития анализатора проект может получить:

- более глубокий анализ XML и ссылок между данными;
- проверку XSLT, ресурсов, DLL/API и Harmony-патчей;
- структурированную базу доказательств совместимости и записи контролируемых A/B/A-тестов;
- оценку рисков с помощью ML — только после проверки качества, первоначально в теневом режиме;
- анализ взаимодействий пар и групп модов;
- понятный режим Simple и подробный режим Advanced;
- отдельный генерируемый мод совместимости через **BCI Compatibility Forge**, без изменения исходных модов;
- необязательного локального AI-помощника для объяснения сложных результатов.

Это направления дальнейшей разработки, а не утверждение, что функции уже реализованы.

## Текущие ограничения

- BCI находится в альфа-стадии, и его выводы требуют проверки.
- Предупреждение не является доказательством неисправности сочетания модов.
- Пока нет валидированной модели-классификатора, обученной на достаточно репрезентативных результатах реальных игровых проверок Bannerlord.
- Прогнозы ML нельзя считать подтверждённой причиной проблемы.
- Compatibility Forge и локальная языковая модель — долгосрочные идеи, а не функции текущей альфа-версии.

## Разработка

Ближайший приоритет — проверить существующий анализатор на реальных установках модов, документировать ложные срабатывания и пропуски, а затем устранить дефекты до расширения глубины анализа.

Последовательность работ и критерии перехода между этапами описаны в [дорожной карте](ROADMAP_RU.md).
