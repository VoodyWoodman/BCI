`scan_total_ms` измеряет только `scan_modules`. В него не входят сравнение с Baseline, ML inference, запись SQLite и экспорт HTML/JSON, выполняемые приложением после сканирования.

## Оптимизация проверки совпадающих ресурсов

- До изменения BCI вычислял SHA-256 для всех файлов при совпадающем относительном пути, даже когда размеры уже различались.
- Теперь сначала сравниваются размеры всех доступных файлов. Если размеры различаются, это достаточно для вывода о различии содержимого; повторное чтение и хеширование больших файлов пропускается.
- Если размеры одинаковые, BCI по-прежнему полностью вычисляет SHA-256 каждого файла. Это сохраняет обнаружение изменений, которые не меняют размер файла.
- Если файл недоступен, отчёт явно помечает сравнение как неполное и не утверждает, что содержимое совпадает.
- Сохранение оригинального регистра относительного пути устраняет зависимость открытия файлов от регистра имён каталогов на файловых системах с учётом регистра.
- В отчёт добавлены `resource_collision_hash_ms`, количество успешно захешированных ресурсных файлов, объём этих файлов, число путей с разными размерами и число файлов, для которых SHA-256 удалось пропустить.
- Добавлены регрессионные тесты для разных размеров, одинакового размера с разным содержимым и одинакового содержимого. Также проверено, что ошибка чтения не маскируется под подтверждённое совпадение.
- Полный набор unit tests после изменения: **21/21 успешно**.

### Исправление Windows build scripts

- `build_windows_exe.bat` и `build_windows_installer.bat` теперь сохраняют открытой консоль при двойном щелчке и показывают итоговый статус до нажатия клавиши.
- Исправлен дефект Python Launcher detection: preflight требует точный sentinel от реально запущенного 64-битного Python нужной версии. Одного нулевого кода возврата `py` недостаточно, так как Windows Python Install Manager может сообщить об отсутствующем runtime без надёжного ненулевого exit code.
- Python 3.12 x64 выбирается первым; Python 3.13 x64 разрешён как fallback. Поддержка 3.13 подтверждается Python classifiers и Windows wheel LightGBM 4.6.0, а PyInstaller поддерживает Python 3.8–3.13.
- Вложенный вызов portable builder из installer запускается с `--no-pause`, чтобы не блокировать сборку. Для версий Python используются отдельные `.build-venv-3.12` / `.build-venv-3.13`.
- Фактический запуск этих BAT-файлов на Windows в текущей среде не выполнялся; требуется проверка на Windows x64.
- После последнего исправления: `python -m pytest -q` — **90 passed**; `python -m unittest discover -s tests -p "test*.py" -q` — **52 OK**; `compileall` Python-модулей и тестов — успешно. Статические проверки BAT пройдены, но Windows Command Processor здесь недоступен, поэтому фактическое переключение на Python 3.13 и создание venv необходимо подтвердить на Windows.
